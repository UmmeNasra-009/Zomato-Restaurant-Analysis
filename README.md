# IBM Cognos Analytics – RetailPulse Business Analytics Practicals

## Project Overview

This project contains practical assignments completed using IBM Cognos Analytics. The main objective is to learn data visualization, report creation, filtering, and dashboard design using RetailPulse retail sales data.

## Practical 1: RetailPulse Sales Summary Report

**Objective:** To create a basic sales report using IBM Cognos Analytics.

**Description:**
Created a report displaying important sales information, including Region, Product Category, and Sales Amount. This practical helped me understand how to create reports and present retail sales data in a structured format.

**Key Learnings:**

* Creating a report in IBM Cognos Analytics.
* Adding data items to a report.
* Displaying sales information in a list format.
* Understanding regional and product category sales.

## Practical 2: RetailPulse Regional Sales Analysis

**Objective:** To analyze sales and quantity across different regions and stores.

**Description:**
Created a grouped report using Region and Store Name, with Product Category, Quantity, and Sales Amount as data items. The report helps organize sales information by region and store for easier comparison.

**Key Learnings:**

* Grouping data by Region and Store.
* Displaying product categories and sales measures.
* Adding totals and report titles.
* Organizing data for better analysis.

## Practical 3: RetailPulse Filtered Sales Report

**Objective:** To filter sales data using region, date, and prompts.

**Description:**
Created a sales report with filtering conditions for the North region and a selected reporting period. This practical helped me understand how filters and prompts can be used to display specific information from a dataset.

**Key Learnings:**

* Applying filters to report data.
* Working with date conditions.
* Using prompts to make reports interactive.
* Displaying data based on selected criteria.

## Practical 4: RetailPulse Region-Product Crosstab

**Objective:** To compare sales and quantity across regions and product categories.

**Description:**
Created a crosstab report showing regions as rows and product categories as columns, with Quantity and Sales as measures. The report provides a structured view of regional product performance and includes totals for comparison.

**Key Learnings:**

* Creating crosstab reports.
* Arranging rows, columns, and measures.
* Comparing sales across regions and product categories.
* Understanding summary totals in reports.

## Practical 6: RetailPulse Customer Insights Dashboard

**Objective:** To create a dashboard for visualizing customer insights.

**Description:**
The practical focuses on designing a dashboard that combines customer summary information, customer trends, loyalty segment analysis, and a Region filter. The intended dashboard helps users explore customer information through visualizations and interactive filtering.

**Key Learnings:**

* Understanding dashboard design in IBM Cognos Analytics.
* Combining multiple visualizations on one canvas.
* Presenting customer trends and loyalty segments.
* Using filters to explore data interactively.

## Tools and Technologies

* IBM Cognos Analytics
* RetailPulse retail sales data
* Data reporting and visualization
* Filters, prompts, crosstabs, and dashboards

## Conclusion

These practical assignments helped me develop a basic understanding of business analytics and data visualization using IBM Cognos Analytics. They demonstrate how reports, filters, crosstabs, and dashboards can help organize business data and support better decision-making.
